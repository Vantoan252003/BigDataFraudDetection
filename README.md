# Big Data Fraud Detection System

## Overview
This project is a real-time fraud detection pipeline for financial transactions. It utilizes an event-driven architecture with Apache Kafka for data streaming, PySpark (Structured Streaming) for data processing and machine learning, PostgreSQL for reliable storage, and Streamlit for an interactive real-time data visualization dashboard.

## Key Features
- **Real-Time Streaming**: Event-driven ingestion using Kafka and Zookeeper (optimized for local runtime).
- **Data Processing & ML**: PySpark pipelines process incoming streams, evaluate transactions, and track model metrics (e.g., AUC-ROC) using **MLflow**.
- **Storage Sink**: PostgreSQL database stores processed and flagged transactions (handling case-sensitive schemas auto-generated by Spark).
- **Interactive Dashboard (Streamlit)**: 
  - *Real-Time Dashboard*: Live metrics and recent fraudulent transactions streaming in.
  - *Transaction Explorer*: Filter, paginate, and search historical transactions directly from the database.
  - *Analytics*: Visual charts (Plotly histograms, bar charts) analyzing fraud distribution by type and time.

## Prerequisites
- **Docker** and **Docker Compose**
- **Git**

## Setup & System Installation

### 1. Clone the repository
```bash
git clone https://github.com/Vantoan252003/BigDataFraudDetection.git
cd BigDataFraudDetection
```

### 2. Add Dataset (🚨 CRUCIAL STEP)
Due to GitHub's file size limits (>100MB), the raw datasets (`paysim.csv`, `creditcard.csv`) are NOT included in the repository. **The system will fail to start if the data is missing.**
1. Create a folder named `data/` in the root of the project.
2. Place your `paysim.csv` file inside the `data/` directory so the Producer can find it.

### 3. Start the Infrastructure
Run the following command to build and start all Docker containers in detached mode:
```bash
docker compose up -d --build
```
*This will spin up Zookeeper, Kafka, Kafdrop, PostgreSQL, MLflow, Streamlit, and the background data consumers.*

### 4. Initialize Data and Train Model
Once the containers are fully up, execute the following PySpark jobs to initialize your database and train the Machine Learning model:

**Step A:** Load initial mock/blacklist data into PostgreSQL
```bash
docker compose run --rm trainer spark-submit jobs/blacklist_loader.py
```

**Step B:** Train the classification model (logs AUC-ROC to MLflow)
```bash
docker compose run --rm trainer spark-submit scripts/train_paysim_model.py
```

*Note: The consumer containers are set up to handle incoming transaction streams automatically.*

### 5. Access the Web Interfaces
After initialization, access the following UIs on your local machine:

- 📊 **Streamlit Dashboard**: [http://localhost:8501](http://localhost:8501) (Explore transactions & Analytics)
- ⚙️ **Kafdrop (Kafka GUI)**: [http://localhost:9000](http://localhost:9000) (Monitor topics, consumer lags, and offsets)
- 📈 **MLflow (Model UI)**: [http://localhost:5000](http://localhost:5000) (Track training runs and evaluation metrics)

## Stopping the System
To safely stop all containers and free up resources:
```bash
docker compose down
```
